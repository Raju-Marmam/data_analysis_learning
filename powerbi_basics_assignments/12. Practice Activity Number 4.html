Power BI Assignment Tasks

  1. Connect to the HPIRegions spreadsheet (note: not the HPIAdmin spreadsheet) in the SourceDataf workbook.
  2. Create a Bar Chart showing:
    • Year(Date) on the X-axis,
    • SUM(Sales Volume) on the Y-axis,
    • Region Name on the Color mark.
    Rename this visualization as "Viz 1".
  3. Create a second visualization:
    • Region Name on the Rows,
    • SUM(Sales Volume) in the Text marks.
    Rename this as "Viz 2".
  4. Create a third visualization:
    • Year(Date) on the Rows shelf,
    • SUM(Sales Volume) in the Text marks.
    Rename this as "Viz 3".
  5. Create a Dashboard that contains:
    • Viz 2 in the top-left corner,
    • Viz 3 in the top-right corner,
    • Viz 1 in the bottom half.
    Think carefully about the best order to add the vizzes into the dashboard.
  6. Enable "Use as Filter" on Viz 2, then click on East Midlands in Viz 2 and observe the effect.
  7. Change the filter so that it only works via a menu.
  8. Add a similar filter on Viz 3.
  9. Set up this dashboard for both Tablet and Phone views.
  10. Create a Story using this dashboard three times. In each story point, select a different region in Viz 2.
